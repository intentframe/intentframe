# Apple Messages

Send iMessages/SMS and read message history on this Mac.

## Available Tools

- `send_message` — Send an iMessage or SMS. Specify `to` (contact name or phone), `text`, and `service` (iMessage or SMS).
- `read_messages` — Read recent messages, optionally filtered by `contact` name or phone number.

## Important

- Always use the dedicated tools above for messaging operations.
