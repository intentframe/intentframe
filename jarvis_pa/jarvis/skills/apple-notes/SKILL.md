# Apple Notes

Create, list, read, and delete notes on this Mac.

## Available Tools

- `create_note` — Create a new note with a title and body.
- `list_notes` — List notes in a folder (leave empty for all).
- `read_note` — Read the full body of a note by title.
- `delete_note` — Delete a note by title.

## Important

- Always use the dedicated tools above for note operations.
