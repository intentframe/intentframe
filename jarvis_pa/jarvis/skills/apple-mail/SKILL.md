# Apple Mail

Send, read, and search emails on this Mac.

## Available Tools

- `send_email` — Send an email. Provide `to`, `subject`, and `body`.
- `read_email` — Read recent emails from a mailbox. Specify `mailbox` and `limit`.
- `search_email` — Search emails by query string.

## Important

- Always use the dedicated tools above for email operations.
