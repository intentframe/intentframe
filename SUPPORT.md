# Support

IntentFrame is a public alpha. The fastest way to get the right response is to use the right channel.

## Questions and Help

Use [GitHub Discussions](https://github.com/intentframe/intentframe/discussions) for:

- setup questions
- design questions
- "can IntentFrame handle this use case?" questions
- agent integration questions
- feedback on docs or roadmap direction

## Bugs and Documentation Issues

Use [GitHub Issues](https://github.com/intentframe/intentframe/issues) for:

- reproducible bugs
- confusing or incorrect documentation
- feature requests with a concrete use case
- suspected non-security boundary behavior that should be discussed publicly

Please include your macOS version, Python version, setup path, and the relevant command output when reporting a bug.

## Security Reports

Do not open a public issue for vulnerabilities or exploitable policy bypasses.

Email **intentframe@gmail.com** and follow the process in [`SECURITY.md`](SECURITY.md).

## Commercial Licensing and Partnerships

IntentFrame is AGPL-3.0-only for open-source use. Commercial licensing is available for organizations that want to use or embed IntentFrame without AGPL obligations.

Email **intentframe@gmail.com** for:

- commercial licensing
- startup or enterprise deployment questions
- partnership conversations
- investor, accelerator, or press inquiries
